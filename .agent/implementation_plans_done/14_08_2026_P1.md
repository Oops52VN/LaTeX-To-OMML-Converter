## 1. Objective
Re-orient the project workspace after laptop migration, purge one-time development and temporary debug artifacts, document all Python and XSLT dependencies in English (`Requirements.md`), build an automated self-healing dependency installer (`install_requirements.py`), and construct a self-contained single-file Windows installer packaging pipeline (`build_release.py` + bundled portable Inno Setup 6).

## 2. Scope & Execution Steps

### Step 1: Workspace Audit & One-Time Artifact Cleanup
1. Scanned the repository root and subdirectories to catalog active source modules (`app.py`), XSLT stylesheets (`MML2OMML.XSL`), frontend assets (`UI/`), and icons (`icons/`).
2. Identified and removed temporary one-off development scripts, debug files, legacy batch scripts, and redundant folders (`old_versions/`).

### Step 2: English Dependency Documentation (`Requirements.md`)
1. Authored `Requirements.md` in 100% English detailing:
   - Core Python dependencies: `PyQt5`, `PyQtWebEngine`, `lxml`, `latex2mathml`, `python-docx`, `pywin32`, `pyinstaller`.
   - External Microsoft Office asset requirement: `MML2OMML.XSL` (extracted from `C:\Program Files\Microsoft Office\root\Office16\MML2OMML.XSL`).

### Step 3: Self-Healing Dependency Installer (`install_requirements.py`)
1. Implemented `install_requirements.py` to:
   - Parse and install required Python packages via `subprocess` and `pip`.
   - Launch `app.py` and monitor process `stderr` for `ModuleNotFoundError` or `ImportError`.
   - Automatically install any detected missing modules and retry until `app.py` initializes cleanly.

### Step 4: Automated Release Packaging Pipeline (`build_release.py` + Portable Inno Setup 6)
1. Diagnosed and resolved the PyInstaller runtime `FileNotFoundError` for `latex2mathml\unimathsymbols.txt` by adding `--collect-data latex2mathml` and `--add-data` flags for `MML2OMML.XSL`, `UI/`, and `icons/`.
2. Bundled a portable installation of **Inno Setup 6** inside `tools/InnoSetup/` (`ISCC.exe`) so installer compilation requires zero external system installations.
3. Implemented `build_release.py` to:
   - Run PyInstaller to freeze `app.py` into a staging directory.
   - Generate an Inno Setup configuration script (`.iss`) and invoke `tools/InnoSetup/ISCC.exe` to output a single standalone `setup.exe` into `releases/`.
   - Execute a post-build cleanup routine that deletes `build/`, `dist/`, `.spec`, and `.iss` temporary artifacts while retaining only the final installer inside `releases/`.
