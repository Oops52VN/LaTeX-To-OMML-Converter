# Implementation Plan P1 — Repository Cleanup, Modular Restructure, Startup Optimization & Governance

- **Plan ID**: `02_11_2026_P1`
- **Date Completed**: 2026-11-02
- **Status**: Completed & Verified

---

## 1. Objective
Audit, clean, and reorganize the **QUAST LaTeX to OMML Converter** repository to eliminate cache/build bloat and dead assets, establish a modular folder hierarchy (`app/`, `core/`, `resources/`), resolve the Windows startup busy-cursor issue, generate an aligned architectural `tree.txt`, and enforce `.agent/` workflow governance rules.

---

## 2. Implementation Phases & Completed Actions

### Phase 1: Cache, Scratch, Duplicate & Dead Asset Cleanup
1. **Cache & Build Artifact Removal**:
   - Removed all `__pycache__/` folders, `.pytest_cache/`, and the Rust `target/` build directory (~1.0 GiB).
2. **Temporary Script Cleanup**:
   - Deleted the root `scratch/` folder (44 ad-hoc debug, patch, and test scripts).
3. **SHA-256 Duplicate & Dead Asset Pruning**:
   - Deleted 59 duplicate `.docx` fixtures in `benchmarks/fixtures/batch_docx/` and `large_formulas_50mb.txt` (~50 MB).
   - Deleted unused icons and assets: `OOPS52_QR_BANKING.png`, `icons/refresh_new.png`, `icons/word_new.png`, `icons/logo_transparent.png`, `icons/logo.png`, `icons/logo.ico`, `UI/assets/iso_logo_clean.svg`, `UI/assets/iso_logo.svg`, and `UI/assets/katex/mhchem.min.js`.
   - Removed `UI/pdfjs/` (372 files, ~16.5 MB) after static analysis confirmed PDF preview relies exclusively on `edge_pdf_viewer.py` + `WebView2Loader.dll`.
4. **Repository Hygiene**:
   - Added `.gitignore` at the project root to prevent caches, build outputs, virtual environments, and OS/IDE artifacts from polluting the workspace.

### Phase 2: Modular Directory Restructure & File Renaming
1. **Directory Consolidation**:
   - Created `app/` for Python application sources (`app.py`, `latex_omml_engine.py`, `image_omml_engine.py`, `edge_pdf_viewer.py`).
   - Created `core/` for the Rust PyO3 accelerator (`Cargo.toml`, `Cargo.lock`, `pyproject.toml`, `src/`, `python/quast_core/`).
   - Created `resources/` for static runtime files (`UI/`, `xsl/`, `bin/`, `icons/`, `files/`).
2. **Path Resolution & Asset Renaming**:
   - Updated `resource_path()` and `locate_xslt()` in `app/app.py` to resolve relative to `resources/`.
   - Updated `get_webview2_loader()` in `app/edge_pdf_viewer.py` to load `resources/bin/WebView2Loader.dll`.
   - Renamed `UI_updated.html` -> `UI.html`, `iso_logo_transparent.svg` -> `iso.svg`, and `tailwindcss.js` -> `tailwind.js`, updating references in `app/app.py` and `resources/UI/UI.html`.
3. **Root Scripts & Dependencies**:
   - Replaced `Requirements.md` with `requirements.txt`.
   - Created `install.bat` (installs `requirements.txt` and optionally builds `core/` via `maturin`) and `run.bat`.

### Phase 3: Windows Startup Busy-Cursor (`IDC_APPSTARTING`) Resolution
1. **Root Cause Analysis**:
   - Profiled Python startup (`import app` ~0.27s, `QApplication` ~0.19s, `WebMainWindow` ~0.50s, `show()` ~0.47s).
   - Identified that `self.word_engine.start()` immediately spawned a headless `WINWORD.EXE` COM server on startup, keeping the Windows startup cursor active.
2. **Code & Launcher Fixes**:
   - Changed `self.word_engine.start()` in `app/app.py` to `QTimer.singleShot(3000, self.word_engine.start)` so the main window renders and processes events before Word COM initialization begins.
   - Updated `run.bat` to launch via `start "" pythonw app\app.py %*`.
   - Cleaned up orphaned background `WINWORD.EXE /Automation -Embedding` processes.

### Phase 4: Project Tree Documentation & `.agent/` Governance
1. **Aligned Project Tree (`tree.txt`)**:
   - Generated a fixed-column, 100% English directory tree with `[CORE]`, `[IMPORTANT]`, `[SUPPORT]`, and `[CONFIG]` tags and an ASCII table detailing how core files operate and interconnect.
2. **`.agent/` Rules & Archival**:
   - Created `.agent/rules/agent_workflow_rules.md` (`trigger: always_on`).
   - Recorded session walkthrough in `.agent/walkthroughes/02_11_2026.md`.
   - Logged normalized English prompt history with UTC+0 timestamps, model names, execution durations, and token estimates in `.agent/prompt_history/Conversation_02_11_2026.txt`.
