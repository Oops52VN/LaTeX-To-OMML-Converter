## 1. Objective
Resolve two critical defects in the `FILE` tab pipeline:
1. **Mixed-Prose Raw LaTeX -> OMML Conversion (`Mixed_English_LaTeX_Formulas.docx`)**: Fix the Rust tokenizer and XML stream transformer so un-delimited LaTeX formulas embedded inside natural-language sentences are accurately isolated from surrounding prose and emitted as inline `<m:oMath>` nodes rather than converting entire paragraphs into a single `<m:oMathPara>`.
2. **Multi-File Preview & Cache Conflicts / Re-rendering**: Eliminate cross-file preview overwrites between input and output `.docx` documents, persist both full and 3-page partial (`_p3.pdf`) previews in `PreviewCacheManager`, prevent heavy Stage 2 exports from blocking fast Stage 1 switching, and remove premature UI spinner resets on cache hits.

---

## 2. Execution Steps

### Step 1: Bidirectional Raw LaTeX Span Segmenter (`core/src/tokenizer/scanner.rs`)
1. Replaced the whole-paragraph `MATH_INDICATORS.iter().any(|cmd| t.contains(cmd))` heuristic with a structural 3-pass scanner (`scan_raw_latex_segments`):
   - **Pass 1 (`lex_raw_tokens`)**: UTF-8-safe lexical scan protecting code blocks, HTTP/HTTPS URLs, and Windows file paths (`ProseLocked`), matching `\begin{env}...\end{env}`, balanced `{...}` groups, full `\command` names (preventing substring false positives like `\to` inside `C:\tools`), Unicode math symbols, numbers, operators, scripts (`^`, `_`), primes, parentheses/brackets, and punctuation.
   - **Pass 2 (`bind_math_atoms`)**: Binds binary/unary LaTeX commands (`\frac`, `\sqrt`, `\vec`, `\mathbf`, etc.) with their arguments and attaches valid mathematical superscripts/subscripts while rejecting `snake_case` prose identifiers.
   - **Pass 3 (`expand` + `merge`)**: Expands rightward and leftward from math anchors across mathematical operators (`=`, `+`, `-`, `\cdot`, `\pm`, etc.), single-letter variables, differentials (`dx`, `d\vec{l}`), bare math functions, and balanced math parentheses, stopping cleanly at natural-language prose words and trailing sentence punctuation.
2. Assigned `is_block = true` only for standalone pure formulas (preserving 100% compatibility with `10000_Formulas.docx`), and `is_block = false` when surrounding non-whitespace prose exists.

### Step 2: Context-Aware Inline vs. Display OMML Emission (`core/src/docx_engine/xml_stream.rs` & `app/app.py`)
1. Updated `process_paragraph` in `xml_stream.rs` to detect `has_surrounding_text` and unwrap `<m:oMathPara>` into inline `<m:oMath>` via `write_omml_for_context` whenever a formula shares a paragraph with prose or has `is_block == false`.
2. Applied matching `effective_block = seg.is_block and not has_surrounding_text` logic in the pure-Python `process_paragraph_xml` fallback in `app/app.py`.
3. Rebuilt `quast_core` in release mode (`cargo build --release`) and updated both `core/python/quast_core/_quast_core.pyd` and `site-packages/quast_core/_quast_core.pyd`.

### Step 3: Two-Tier Cache, Prioritized Preview Queue & Race Guards (`app/app.py`, `app/edge_pdf_viewer.py`, `resources/UI/UI.html`)
1. **Two-Tier Versioned `PreviewCacheManager` (`app/app.py`)**:
   - Keyed both `_memory_cache` (full PDF) and `_partial_cache` (`_p3.pdf`) by `(norm_path, sha256(norm_path|mtime_ns|size))`.
   - Added `get_cached_preview(docx_path) -> (pdf_path, is_partial)` and `register_partial_cache(...)`.
2. **3-Tier Prioritized `PersistentWordPdfEngine` (`app/app.py`)**:
   - Split scheduling into `_active_stage1_queue` (priority 1), `_bg_stage1_queue` (priority 2), and `_bg_stage2_queue` (priority 3 with a 1.0s cooldown so rapid file switching is never blocked behind heavy Stage 2 exports).
   - Preserved Stage 2 caching even when the user switches files mid-queue, and added `clear_active_request()` for instant cache hits.
3. **Strict File-Identity & Navigation Guards (`app/app.py`, `app/edge_pdf_viewer.py`, `resources/UI/UI.html`)**:
   - Invalidated `current_preview_req_id` and `word_engine` active request on full cache hits; verified `docx_path == current_preview_file` in `on_preview_ready`.
   - Added `_batch_gen` generation guard for 600ms deferred pre-caching timers.
   - Added `_nav_seq` monotonic sequence guard and `_should_be_visible` check in `EdgePdfPreviewHost` to drop stale `singleShot` / `NavigationCompleted` signals and skip redundant navigation on the same PDF path.
   - Removed premature `showPreviewLoader(true)` from `setFileList` `div.onclick` in `UI.html` so cache hits render immediately with zero spinner flash, and cleared `currentActivePdfUrl` when entering `showPreviewLoader(true)`.
