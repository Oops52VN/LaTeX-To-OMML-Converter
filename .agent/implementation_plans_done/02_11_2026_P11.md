## 2. Scope & Execution Details

### 2.1. Strict CSS Scoping for `vscode-markdown.css`
- **Root Cause**: The raw VS Code Markdown stylesheet contained global styling for `html, body` (`padding: 0 26px; font-size: 14px; line-height: 22px;`), `body` (`padding-top: 1em;`), and bare tags (`h1-h6`, `p`, `table`, `a`, focus rings).
- **Execution**: Rewrote all selectors in [`resources/UI/assets/vscode-markdown.css`](resources/UI/assets/vscode-markdown.css) so every single rule is strictly scoped under `#view-readme .vscode-markdown-content` or `#view-readme #readme-content-scroll.vscode-body`. No global tag or root styling touches elements outside `#view-readme`.

### 2.2. Strict CSS Scoping for `github-markdown.min.css`
- **Root Cause**: The compound selector `.markdown-body,[data-theme=dark]` matched `<html data-theme="dark">`, applying markdown body typography and variables globally to the root document.
- **Execution**: Replaced `.markdown-body,[data-theme=dark]` with `[data-theme=dark] .markdown-body` and `.markdown-body,[data-theme=light]` with `[data-theme=light] .markdown-body` in [`resources/UI/assets/github-markdown.min.css`](resources/UI/assets/github-markdown.min.css).

### 2.3. QWebChannel Atomic Initialization & Defensive Dispatch
- **Root Cause**: `initWebChannel()` was invoked three times asynchronously before `window.backend` was set, replacing `qt.webChannelTransport.onmessage` and losing callback references for pending response IDs.
- **Execution**:
  - Implemented an atomic initialization guard: `var isWebChannelInitialized = false;` in [`resources/UI/UI.html`](resources/UI/UI.html).
  - Monkeypatched `channel.handleResponse` to safely handle orphan response IDs without throwing uncaught runtime TypeErrors.
  - Removed duplicate `initWebChannel()` calls on `window.load` and inside `DOMContentLoaded`.

### 2.4. Hardened Window & Body Layout Constraints
- Enforced strict CSS resets in [`resources/UI/UI.html`](resources/UI/UI.html):
  ```css
  html, body {
      margin: 0 !important;
      padding: 0 !important;
      width: 100vw !important;
      height: 100vh !important;
      overflow: hidden !important;
      box-sizing: border-box !important;
  }
  body {
      padding: 7px !important;
      overflow: hidden !important;
  }
  ```
