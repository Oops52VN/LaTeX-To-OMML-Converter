# Implementation Plan — `19_11_2026_P3`

- **Goal**: Hide the Windows title bar (caption) icon on `WebMainWindow` while preserving the full `app.ico` icon on the Windows Taskbar and Alt+Tab switcher.
- **Scope**:

1. Inspected Win32 `WM_SETICON` / `WS_EX_DLGMODALFRAME` / `GCLP_HICONSM` behavior on Windows 11 DWM via `PrintWindow` capture. 2. Added `WebMainWindow._get_transparent_small_hicon()` in `app/app.py` using 64-bit-safe `ctypes.wintypes` GDI/User32 signatures (`CreateBitmap`, `CreateIconIndirect`, `DeleteObject`).
3. Updated `WebMainWindow._remove_titlebar_icon()` to apply `WS_EX_DLGMODALFRAME` and assign the cached transparent 16x16 `HICON` to `WM_SETICON(ICON_SMALL)` and `GCLP_HICONSM`, leaving `ICON_BIG` untouched.
4. Updated `WebMainWindow.closeEvent()` to release the cached `HICON` via `DestroyIcon`.
5. Verified `WebMainWindow` live via `PrintWindow` bitmap inspection and `WM_GETICON` queries.
