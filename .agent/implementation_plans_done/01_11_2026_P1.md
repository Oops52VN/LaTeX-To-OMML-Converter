## 1. Objective
Refactor the monolithic `app.py` (~1,141 lines) into a clean, multi-layered modular architecture (`source_app/`), remove all unused raster icon assets while standardizing active icons to SVG format, and completely eliminate the obsolete `"VIBE"` (unfinished Gemini API experiment) and `"SETTINGS"` placeholder tabs from both the frontend HTML/JS and backend Python codebase.

## 2. Scope & Execution Steps

### Step 1: Resource & Icon Directory Cleanup
1. Audited the workspace and excluded obsolete release binaries (`releases/*.exe`, `*.zip`, `*.mp4`), temporary `tools/innosetup.exe`, and empty `old_versions/`.
2. Audited `icons/`:
   - Removed unused large PNG files: `refresh_new.png` (20.9 KB) and `word_new.png` (503.9 KB).
   - Retained standardized SVG icons (`latex.svg`, `refresh.svg`, `word.svg`), created `logo.svg`, and retained `logo.ico` for Windows PE executable headers.
3. Created `requirements.txt` specifying `PyQt5`, `PyQtWebEngine`, `lxml`, `latex2mathml`, `python-docx`, and `pywin32`.

### Step 2: Complete Removal of Legacy `VIBE` and `SETTINGS` Features
1. Edited `UI/UI_updated.html` to remove:
   - Header buttons `#tab-vibe` and `#tab-settings`.
   - View containers `#view-vibe` and `#view-settings`.
   - JavaScript branches for `vibe` and `settings` in `switchTab(tabId)`, as well as dead functions `handleGenerate()`, `callGeminiAPI()`, `apiKey`, and duplicate `resizeObserver` declarations.
2. Added null-safety guards on DOM selectors to eliminate JavaScript console errors.

### Step 3: Modular Codebase Decomposition (`source_app/`)
1. **Configuration & Utilities (`source_app/config.py`, `source_app/utils/`)**:
   - Extracted `WORD_NAMESPACE` and `NSMAP` constants into `config.py`.
   - Extracted `resource_path()` and `locate_xslt()` into `utils/paths.py`.
   - Extracted Qt environment setup, Chromium GPU flags, and crash logging into `utils/env.py`.
2. **Core Business Logic (`source_app/core/`)**:
   - `latex_converter.py`: `convert_latex_to_omml`, `convert_latex_snippet_to_omml`, `save_latex_to_docx`.
   - `docx_processor.py`: `add_text_to_paragraph`, `process_paragraph_xml`, `preprocess_word_for_preview`.
   - `workers.py`: `PreprocessWorker`, `ConversionWorker`, `COMKeepAliveWorker`.
3. **UI & Tab Controllers (`source_app/ui/`)**:
   - `preview_manager.py`: `ZStackPreviewManager`.
   - `tabs/file_tab.py` (`FileTabController`), `tabs/latex_tab.py` (`LatexTabController`), and `tabs/image_tab.py` (`ImageTabController`).
   - `bridge.py` (`Backend` `QWebChannel` slots) and `main_window.py` (`WebMainWindow`).
4. **Concise Entry Point (`app.py`)**:
   - Reduced `app.py` from 1,141 lines to 44 lines responsible solely for environment initialization and launching `WebMainWindow`.
