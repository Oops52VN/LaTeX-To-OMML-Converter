## 1. Objective
Fix the file naming logic in `.agent/rules/agent_workflow_rules.md` so that walkthroughs, implementation plans, and prompt histories from separate conversations/sessions on the same date are never merged into a single file, and restructure all existing `.agent/` archives to strictly follow the new per-session naming conventions:
- **Walkthroughs**: `<DD>_<MM>_<YYYY>_W<No>.md`
- **Implementation Plans**: `<DD>_<MM>_<YYYY>_P<No>.md`
- **Prompt Histories**: `<DD>_<MM>_<YYYY>_C<No>.txt`

## 2. Scope & Execution Steps

2. Updated **Rule 3 (Completed Implementation Plans)** to use `<DD>_<MM>_<YYYY>_P<No>.md` (`e.g., 02_11_2026_P1.md`).
3. Updated **Rule 4 (User Prompt History Logging)** to mandate per-conversation separation using `<DD>_<MM>_<YYYY>_C<No>.txt` (`e.g., 02_11_2026_C1.txt`).

### Step 2: Split & Rename Prompt Histories (`.agent/prompt_history/`)
