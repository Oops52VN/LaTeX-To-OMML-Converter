## 1. Goal Description
Achieve comprehensive GPU hardware acceleration across all application components (Chromium QtWebEngine and Microsoft Edge WebView2), transition the frontend architecture from lazy-loading to an eager all-loading pre-caching pipeline during the startup splash phase to eliminate cross-tab navigation latency, restore the classic startup splash screen layout (circular rotating spinner with prominent, large typography) per user preference, and update the technical documentation button label to "ABOUT" with an Information icon.

## 2. Scope & Technical Architecture

### 2.1 Full GPU Hardware Offloading (Section B Spec)
1. **Host & WebEngine Flag Pre-Configuration**:
   - Elevated `QTWEBENGINE_CHROMIUM_FLAGS` definition to the absolute top of `app/app.py` before any PyQt5 or QtWebEngine module imports, preventing DLL load race conditions.
   - Enforced flags (`--enable-gpu-rasterization --enable-zero-copy --enable-accelerated-2d-canvas --ignore-gpu-blocklist --disable-gpu-vsync=0`).
   - Injected `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS` (`--enable-gpu-rasterization --enable-zero-copy --enable-accelerated-2d-canvas --ignore-gpu-blocklist`) in `app/app.py` and `app/edge_pdf_viewer.py` so the secondary Microsoft Edge WebView2 engine (`msedgewebview2.exe`) executes with full GPU rasterization and compositing.
2. **CSS GPU Compositing Layers (`resources/UI/UI.html`)**:
   - Promoted heavy scrolling viewports (`#readme-content-scroll`, `#iso-content-scroll`, `#view-latex`, `#view-image`, `#input-file-list`, `#output-file-list`) to independent hardware compositing layers using `transform: translateZ(0)`, `will-change: scroll-position`, and `contain: paint layout`.

### 2.2 Classic Startup Splash Screen (Turn 3 User Preference)
1. **Visual Hierarchy & Geometry (`QtLoadingOverlay`)**:
   - Restored and refined the classic minimalist layout featuring an anti-aliased 46x46 circular spinner (`SpinnerWidget`, 3.0px pen width, dark track circle `#2d3037` and vibrant blue rotating arc `#3b82f6`).
   - Sized typography generously:
     - Title: `QLabel("LATEX TO OMML CONVERTER")`, styled with `font-size: 17px; font-weight: 700; letter-spacing: 3.5px; color: #ffffff;`.
     - Subtitle status: `QLabel("INITIALIZING...")`, styled with `font-size: 12px; font-family: monospace; letter-spacing: 2px; font-weight: 500; color: #9ca3af;`.
   - Removed progress bar widget completely to keep visual presentation uncluttered and focused.
2. **Smooth Dismissal & Fallback Timeout**:
   - Implemented two-stage fade-out: 280ms content (spinner + text) opacity fade, followed by 500ms background `#141518` fade synchronized with Windows DWM title bar theme transition.
   - Installed a 9000ms safety timer (`on_preload_timeout_fallback`) to guarantee that the loading overlay automatically dismisses and transitions into the main UI even if any asset stalls.

### 2.3 Eager All-Loading Pipeline & Navigation Refactoring
1. **Frontend Preload Pipeline (`window.quastStartEagerPreload`)**:
   - **Phase 1 (20–55%)**: GPU & DOM structure initialization, hardware scroll container setup.
   - **Phase 2 (70%)**: KaTeX engine & math font pre-warming (pre-rendering sample inline/display formulas offscreen to load WOFF2 glyphs into GPU VRAM and compile V8 AST parsers).
   - **Phase 3 (85%)**: Documentation & vector diagram eager pre-rendering (fetching `README.md`, parsing with Markdown-It, and compiling all Mermaid SVG diagrams into the DOM).
   - **Phase 4 (95%)**: Global cache synchronization across all tab view elements.
   - **Phase 5 (100%)**: Dispatch completion signal (`signal_frontend_ready`) to Python backend.
2. **Zero-Latency Tab Navigation**:
   - In `switchTab('readme')`, eliminated the 270ms deferred rendering delay since all Markdown and Mermaid SVG diagrams are already pre-rendered in DOM.
3. **ABOUT Button & Information Icon (Turn 4)**:
   - Updated header tab button `#tab-readme` label to "ABOUT" with `<i class="fa-solid fa-circle-info mr-2 text-sm"></i>`.
