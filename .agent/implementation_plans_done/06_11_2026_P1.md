## 1. Goal Description
Package the complete QUAST LaTeX to OMML Converter into a single standalone Windows setup installer executable ("bộ cài duy nhất"), branded and titled as the trial release ("bản thử nghiệm"), outputted directly into `releases/Ban_Thu_Nghiem_Setup.exe` (with direct alias `releases/Ban_Thu_Nghiem.exe`).

---

## 2. Scope & Technical Architecture

### 2.1. Packaging Strategy
- Use PyInstaller to freeze the Python codebase (`app/app.py`), UI web assets (`resources/UI/`), XSLT stylesheets (`resources/xsl/`), WebView2 loader binary (`resources/bin/`), and native Rust accelerator (`quast_core`) into a staging onedir directory.
- Exclude heavy, non-critical machine learning frameworks (`paddle`, `paddleocr`, `torch`) to preserve an ultra-compact binary size (~125 MB instead of >2.5 GB) while maintaining full functionality of the core conversion engines (DOCX batch engine, LaTeX AST engine, Edge PDF viewer, and OpenCV image preprocessor).
- Generate a multi-resolution Windows icon (`resources/icons/app.ico`) from `resources/UI/assets/logo.png` covering resolutions from 16x16 to 256x256.
- Bundle and utilize portable Inno Setup 6 (`tools/InnoSetup/ISCC.exe`) with LZMA2/ultra64 solid compression to generate a single-file installer wizard with Start Menu and Desktop shortcuts.
- Implement an automated post-build cleanup routine to purge all intermediate directories (`build/`, `dist/`, `.spec`, `.iss`).
- Provide an automated build runner (`build_release.py`) and single-click Windows batch launcher (`package.bat`).
