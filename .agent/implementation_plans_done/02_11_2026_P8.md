## 1. Goal Description
The objective of this task is to design and integrate an additional "README" navigation tab and full-page interactive viewer positioned directly alongside the existing ISO 80000 technical standard page within the application UI (`resources/UI/UI.html`). The page must render Markdown according to current standards (GFM, tables, code blocks with syntax highlighting, vector Mermaid diagrams, KaTeX formulas, and local badges/images) while providing verbatim access to the `README.md` file from disk.

## 2. Scope & Technical Architecture
1. **Frontend Navigation Tab & Layout**:
   - Add `#tab-readme` button directly adjacent to `#tab-iso` in the top navigation bar with Font Awesome `fa-brands fa-readme` icon.
   - Create full-height `#view-readme` container with dual viewing modes:
     - **Rendered Markdown View**: High-fidelity GitHub Markdown layout using `github-markdown.min.css`.
     - **Raw Source View**: Verbatim code canvas inside `<pre><code id="readme-raw-code">` with line wrapping and monospace font.
   - Add top toolbar controls:
     - Mode switch button (`View Raw Source` / `View Rendered`).
     - One-click `Copy Markdown` button interacting directly with Windows OS Clipboard.
     - `Scroll to Top` helper button.
     - Live synchronization badge and status text.

2. **Offline Rendering Engines & Asset Bundling**:
   - Bundled `marked.min.js` (GFM parser), `mermaid.min.js` (v10.9.1 SVG vector diagrams), `highlight.min.js` (syntax highlighting), `github-markdown.min.css`, `github-dark.min.css`, and `github.min.css`.
   - Pre-cached 19 official Shields.io badges as local SVGs into `resources/UI/assets/shields/` to maintain 100% offline air-gapped security.
   - Implemented `readme_bundle.js` with base64 embedded data URIs for all screenshots, icons, and SVG shields as an offline fallback.
