## 1. Goal Description
The objective of this task is to deliver a complete, production-ready, error-free architecture for rendering local `README.md` documents inside an embedded Python WebView component. The implementation addresses five core technical challenges:
1. Neutralizing Tailwind CSS preflight interference with `github-markdown.min.css`.
2. Configuring `marked.js` with `highlight.js` syntax highlighting.
3. Enforcing a strict three-phase synchronous render pipeline: Marked HTML -> KaTeX Math (`renderMathInElement`) -> Mermaid Diagrams (`mermaid.init`).
4. Preventing LaTeX escape character degradation (`\alpha`, `\frac`, `\newline`) across Python-to-JS IPC boundaries using UTF-8 Base64 serialization and browser `TextDecoder` rehydration.
5. Resolving relative markdown image URLs (e.g., `./screenshots/...`) to absolute `file:///` filesystem URLs based on the host Python application root.

## 2. Technical Scope & Architecture

### 2.1. CSS Isolation & Tailwind Preflight Containment
- Wrap markdown content in `<div class="markdown-body" id="readme-container">`.
- Apply targeted specificity overrides to guarantee headings (`h1`–`h6`), unordered/ordered lists (`ul`, `ol`, `li`), tables, and blockquotes preserve authentic GitHub styling despite Tailwind's aggressive unstyled reset.
- Provide adaptive light/dark theme styling syncing seamlessly with parent theme modes.

### 2.2. Markdown Parser & Syntax Highlighting
- Leverage `marked.min.js` (supporting v15+ object signatures and legacy signatures).
- Hook into code rendering:
  - Divert `lang === 'mermaid'` into `<div class="mermaid">` nodes for deferred SVG rendering.
  - Route code blocks through `hljs.highlight(code, { language })` with fallback to `hljs.highlightAuto(code)`.

### 2.3. Three-Stage Synchronous Pipeline
- **Phase 1 (HTML Generation)**: Parse markdown string to HTML and inject into DOM container.
- **Phase 2 (KaTeX Math Rendering)**: Execute `renderMathInElement` with delimiter coverage for `$$`, `$`, `\[`, and `\(`. Include an embedded fallback polyfill to guarantee zero failure if `auto-render.min.js` is absent from assets.
- **Phase 3 (Mermaid Vector Synthesis)**: Call `mermaid.init` specifically targeting generated `.mermaid` elements with responsive theming.

### 2.4. Lossless IPC Bridge (Python <-> JavaScript)
- **Python**: Read `README.md` in UTF-8, encode bytes via `base64.b64encode`, and return clean ASCII Base64.
- **JavaScript**: Ingest Base64, convert binary string to `Uint8Array`, and decode via `new TextDecoder('utf-8').decode(bytes)`.

### 2.5. Relative Local Image Resolution
- Override `renderer.image` in Marked.
- Detect non-remote paths (`./`, relative subpaths) and concatenate with `window.BASE_APP_DIR` formatted as standardized `file:///` URIs.
