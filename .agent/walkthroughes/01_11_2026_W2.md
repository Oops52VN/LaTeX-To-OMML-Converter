## 2. Architectural Conclusions
- Recommended a **Hybrid Python + Rust (`PyO3` / `maturin`)** architecture rather than a full GUI rewrite:
  1. **Retain in Python**: PyQt5/WebEngine UI shell, `QWebChannel` bridge, Microsoft Word COM automation (`pywin32`), and XSLT/AST orchestration.
  2. **Migrate to Rust (`PyO3` native extension)**:
     - Multi-threaded `.docx` ZIP/XML streaming I/O (`zip` + `quick-xml` + `rayon`).
     - High-speed single-pass LaTeX delimiter and formula tokenization (`memchr` + `regex`).
     - Pure-Rust mathematical image preprocessing (`image` + `rayon`) for OCR.
