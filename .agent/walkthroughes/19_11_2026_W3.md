## 1. Root Cause Analysis
- Commit `bd4a8dd` replaced `WebMainWindow`'s 16x16 transparent `QPixmap` with `self.setWindowIcon(QIcon(icon_path))` so the Windows Taskbar and Alt+Tab would render `resources/icons/app.ico`.
- Calling `setWindowIcon(QIcon(icon_path))` caused Qt to set both `ICON_BIG` and `ICON_SMALL` on the Win32 `HWND`. On Windows 11 DWM, `WS_EX_DLGMODALFRAME` alone does not suppress the caption icon when `ICON_SMALL` is non-null, and clearing `ICON_SMALL` to `0` causes DWM to fall back to `ICON_BIG` in the title bar.

---

## 2. Changes Applied
- **`app/app.py`**:
  - Added `WebMainWindow._get_transparent_small_hicon()` to construct and cache a 16x16 100%-transparent Win32 `HICON` via `CreateIconIndirect` with explicit 64-bit `ctypes.wintypes` handle types.
  - Updated `WebMainWindow._remove_titlebar_icon()` to retain `WS_EX_DLGMODALFRAME` and assign the 16x16 transparent `HICON` to `WM_SETICON(ICON_SMALL)` and `GCLP_HICONSM`, keeping `ICON_BIG` (`app.ico`) intact for the Taskbar and Alt+Tab switcher.
  - Updated `WebMainWindow.closeEvent()` to destroy the cached `HICON` with `DestroyIcon` on window close.
