   - Asynchronous race conditions caused `new QWebChannel` to be constructed 3 times on launch, continuously overwriting `qt.webChannelTransport.onmessage` and triggering `Uncaught TypeError: channel.execCallbacks[message.id] is not a function` at `qwebchannel.js:137`. This severed the communication bridge between JavaScript and the Python PyQt backend.
