## 2. Key Technical Findings & Architectural Decisions
- **Main Thread Decongestion**: Identified that synchronous `katex.render()` and monolithic JSON string parsing caused frequent 40ms–120ms frame drops on the WebView2 main thread. Solved by decoupling formula evaluation into a dedicated Web Worker using `katex.renderToString()`, reducing main-thread overhead to sub-4ms DOM updates.
- **Forced Reflow Elimination**: Discovered layout thrashing patterns where sidebar/header styles were mutated immediately before geometry read queries (`getBoundingClientRect()`, `offsetWidth`). Replaced layout-triggering properties (`width`, `height`, `margin`) with composite-only properties (`transform: translate3d/scale3d` and `opacity`).
- **Cold Start & FOUC Eradication**: Identified the 3.33 MB `mermaid.min.js` and 407 KB `tailwind.js` synchronous script payloads as the primary cause of cold-start delays. Designed a deferred loading strategy (dynamic script injection when navigating to the documentation tab) and pre-compiled CSS styling to eliminate FOUC and bring CLS to 0.00.
- **Physics-Based Animation Model**: Replaced linear and basic ease-in-out transitions with a damped harmonic oscillator spring model ($m \ddot{x} + c \dot{x} + k x = 0$) and calibrated cubic-bezier curves for responsive, natural motion.
