## 1. Overview
Investigated why executing `run.bat` failed to launch the application. Diagnosed an interpreter mismatch where the generic `pythonw` executable in `PATH` pointed to a separate, unconfigured Python 3.14 installation rather than the primary Python 3.13 environment containing all project dependencies. Hardened `run.bat` with dynamic binary resolution and ensured `app/app.py` self-configures its module resolution paths.

## 2. Completed Milestones

### 2.1. Root Cause Identification
- Inspected all Python binaries on `PATH` using `where.exe`:
  - `python`: `C:\Users\trann\AppData\Local\Microsoft\WindowsApps\python.exe` (Python 3.13, all packages installed).
  - `pythonw`: `C:\Users\trann\AppData\Local\Python\bin\pythonw.exe` (Python 3.14, bare environment missing `numpy`, `PyQt5`, etc.).
- When `run.bat` called `start "" pythonw app\app.py`, Windows invoked Python 3.14, failing immediately upon importing dependencies with `ModuleNotFoundError: No module named 'numpy'`.
- Additionally, running `app\app.py` from the root workspace directory without `app/` in `sys.path` posed an import resolution risk for sibling modules (`latex_omml_engine`, `image_omml_engine`, `edge_pdf_viewer`).

### 2.2. Robust Launcher Architecture (`run.bat`)
- Completely refactored `run.bat`:
  1. Validates that `python` is available on the machine.
  2. Dynamically queries the active `python` interpreter directory to resolve the exact matching windowless executable (`pythonw.exe`, `pythonw3.exe`, or `pythonw3.13.exe`).
  3. Launches the application silently using the resolved binary.
  4. Provides graceful cascading fallbacks (`pythonw3` -> `pythonw` -> `python`) and helpful user guidance if Python is missing.

### 2.3. Resilient Module Resolution (`app/app.py`)
- Injected guaranteed path resolution at the top of [`app/app.py`](file:///e:/Documents/Q7%20LaTeX%20To%20OMML%20Python/app/app.py#L3-L12):
  - Injects `app/` into `sys.path[0]`.
  - Injects the workspace root into `sys.path[1]`.
  - Guarantees seamless imports regardless of the active working directory or how the process was spawned.
