=====================================

+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| File                                 | How it works                                                   | Connects to                                  |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| run.bat                              | Starts pythonw app\app.py without a console window.            | app/app.py                                   |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| package.bat                          | Runs build_release.py to build standalone installer.           | build_release.py, releases/                  |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| build_release.py                     | Automates PyInstaller freezing and Inno Setup 6 compilation.   | app/app.py, tools/InnoSetup, releases/       |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| install.bat + requirements.txt       | Installs Python libraries; optionally builds/installs the Rust | core/pyproject.toml, core/Cargo.toml         |
|                                      | wheel with maturin.                                            |                                              |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| app/app.py                           | Entry point. Creates the Qt window, loads UI.html, exposes     | UI.html, latex_omml_engine,                  |
|                                      | Backend to JavaScript, runs conversion / preview / OCR in      | image_omml_engine, edge_pdf_viewer,          |

+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| resources/UI/UI.html                 | Front-end. Calls Python slots (convert files, compile LaTeX,   | app/app.py, katex, tailwind, fontawesome     |
|                                      | OCR image, preview) over QWebChannel and renders results.      |                                              |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| app/latex_omml_engine.py             | Tokenizes LaTeX, builds an AST and emits OMML XML directly (no | Imported by app.py and image_omml_engine.py  |
|                                      | XSL). Also builds MathML previews.                             |                                              |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| app/image_omml_engine.py             | Image -> preprocess (Rust or OpenCV) -> PaddleOCR LaTeX ->     | quast_core (optional), latex_omml_engine,    |
|                                      | normalize -> OMML.                                             | app.py                                       |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| app/edge_pdf_viewer.py               | Hosts an Edge WebView2 control in a Qt widget to show PDFs     | WebView2Loader.dll, app.py                   |
|                                      | made by the Word preview engine.                               |                                              |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| core/python/quast_core/__init__.py   | Imports the compiled Rust module, sets HAS_RUST_CORE, provides | app.py, image_omml_engine.py,                |
|                                      | a pure-Python fallback for batch DOCX conversion.              | core/src/lib.rs                              |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| core/src/lib.rs                      | PyO3 module root; registers docx_engine, image_proc, tokenizer | docx_engine/, image_proc/, tokenizer/        |
|                                      | functions and the thread pool.                                 |                                              |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| core/src/docx_engine/xml_stream.rs   | Streams word/document.xml, finds LaTeX formulas and rewrites   | tokenizer/scanner.rs, batch_runner.rs        |
|                                      | them as OMML (parallel via batch_runner.rs).                   |                                              |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| core/src/tokenizer/scanner.rs        | Fast scanner for $...$ / $$...$$ segments; normalizer.rs       | docx_engine/, Python wrapper                 |
|                                      | cleans the extracted LaTeX.                                    |                                              |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+
| resources/xsl/MML2OMML.XSL           | XSLT for the MathML -> OMML route when Office's own copy is    | app.py (locate_xslt)                         |
|                                      | not found.                                                     |                                              |
+--------------------------------------+----------------------------------------------------------------+----------------------------------------------+

Runtime flow:
  run.bat -> app/app.py -> loads resources/UI/UI.html (QWebEngine) -> user action in UI
  -> Backend slot in app.py ->
       LaTeX text : latex_omml_engine
       DOCX batch : quast_core (Rust) or Python fallback
       Image      : image_omml_engine
  -> OMML written into DOCX / copied to clipboard.
  DOCX preview: Word COM -> PDF -> Edge WebView2.
